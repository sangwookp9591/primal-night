# 설계 문서-코드 정렬 표

기준 문서: `docs/design/GAME_SCENARIO_WORLD_TILEMAP.md` 전체.
정렬 기준: `docs/PRIMAL_NIGHT_GITHUB_AUDIT_AND_AGENT_LOOP.md` §0의 새 원칙과 현재 main HEAD 코드.

## 정렬 원칙

1. 새 원칙 문서 §0이 제품 방향의 상위 정본이다. 특히 20~30분짜리 3구역 수직 절편, 퀘스트 목록 없는 세계 변수 탈출, 싱글→2인→4인 검증 순서를 우선한다.
2. `LoopObjective`의 세션 판정은 고정 부품 납품이 아니라 위험 노출, 지혈, 불 유지, 추출 도달, 생존 여부로 갈린다. 설계 문서의 `부품 3개 없이는 탈출 불가`, `부품 A/B/C 회수 후 신호기 가동` 서술은 폐기 대상으로 본다.
3. 4인은 목표로만 유지한다. `host + 3 clients` 장기 검증 전에는 출시 약속이나 상점/데모 사양으로 쓰지 않는다.
4. 월드는 40청크 골격을 보존하되, 현재 진행은 Z01/Z02/Z03 수직 절편 밀도 검증이 우선이다. Z04/Z05와 40청크 전체 콘텐츠 즉시 채우기는 후순위다.
5. 코드가 이미 설계 문서를 앞선 항목은 구현 완료처럼 원 설계 문서에 덧쓰지 않고, 이 문서의 "문서 미기재" 또는 "코드가 앞섬" 행으로 추적한다.
