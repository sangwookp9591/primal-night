## 3. 검증

### 자동 회귀

```
GUT: Scripts 61 / Tests 342 / Passing 342 / Asserts 1385+ / 실패 0
Sense loop harness: seed 4001~4010 10/10 PASS (생산자 경유 전환 후)
tests/net: 3회 연속 46~47/47 (동적 포트, 경합 재현 없음)
```

시작 시점 기준선은 266 tests 였다. +76 테스트에는 실기 InputEvent 주입 경로 테스트
(잘못된 키 바인딩으로 되돌리면 4개 RED), 스폰 직후 피로 0 회귀, 지식 발견/복원 계약이 포함된다.

### 실기 플레이 (macOS, Godot 4.7.1, GUI 실행 + 자동 입력)

- 이동(WASD)·줍기(E)·디버그 피해(H)·치료 홀드(E), 낮→황혼→밤 위상 전환, 생존 HUD 4종 표시.
- C 우선순위 제작: 재료 구성에 따라 미끼→돌칼→횃불→뼈 긁개→원격 소음 미끼가
  각각 제작·소비됨을 확인. 재료 부족 시 하위 레시피 폴백/무동작 정확.
- F 설치: 원격 소음 미끼 소비 + 설치 마커 생성 (발동·소음은 GUT 검증).
- R 순환: 밀집 아이템에서 "뼈 x2 줍기" ↔ "돌 x1 줍기" 순환 후 E 가
  최근접이 아닌 **선택 대상**을 픽업.
- 지식 발견: 뼈 긁개 최초 제작 순간 관찰문 "섬유로 감으니 뼈날을 손에 쥘 수 있다."
  HUD 알림 표시.

### 실기 검증이 잡아낸 것 (자동 테스트가 놓친 것)

1. 월드에 신규 재료 스폰이 없어 제작 체인이 플레이 불가 → `421440b`
2. `cycle_target` 이 Backspace 에 오바인딩 — GUT 가 `cycle_target()` 을 직접 호출해
   통과했기 때문에 미검출. 실기 재현 → 계측 진단 → 키 R 확정 + 입력 경로 주입 테스트 → `dd7dc3f`

## 5. 오케스트레이션 운영 메모

- codex 계열 워커는 `-c sandbox_workspace_write.network_access=true` 없이는 Orca RPC
  (`worker_done`)와 ENet 테스트가 모두 막힌다. claude 워커는 제약 없음.
- 워커 샌드박스에서 Godot 이 `user://` 접근 실패로 크래시할 수 있어 (`HOME=/tmp/...` 우회
  또는) 전체 GUT 회귀는 코디네이터가 대행하는 흐름을 기본으로 뒀다.
- 같은 워크트리 병렬 작업은 태스크별 파일 소유권을 스펙에 명시해 충돌 0건으로 완료.
  단, 병렬 작업 중 전체 GUT 는 타 워커의 중간 상태에 오염될 수 있어 (game_data.gd 파스
  에러 사례) 범위 축소 실행 후 통합 시점에 전체 회귀를 돌린다.
