# PRIMAL NIGHT 에셋 생성 정책

- 상태: 확정 (사용자 지시)
- 작성일: 2026-07-14
- 적용 범위: 스프라이트, 타일, 아이콘, 이펙트 등 생성형으로 만드는 모든 2D 에셋
- 관련 문서: `docs/superpowers/specs/2026-07-13-primal-night-design.md` (11장 시각 방향), `docs/superpowers/plans/2026-07-13-primal-night-asset-style-comparison.md` (스타일 선택)

## 1. 담당

에셋 생성은 **GPT sol**(`gpt-5.6-sol`)이 담당한다.

다른 모델로 대체하지 않는다. 모델이 바뀌면 같은 프롬프트라도 선 굵기, 채도, 명암 처리, 실루엣 해석이 달라져 이미 만든 에셋과 어긋난다. 에셋은 코드와 달리 "돌아가기만 하면 되는" 것이 아니라 서로 **닮아야** 하는 산출물이다.

## 2. 방향 세트는 반드시 한 번에 생성한다

### 2.1 규칙

방향이 있는 에셋(캐릭터, 공룡, 이동하는 오브젝트)은 **8방향 전체를 단 한 번의 요청으로 한꺼번에 받는다.**

- 8방향: N, NE, E, SE, S, SW, W, NW
- 애니메이션 프레임이 있으면 **프레임까지 포함해 한 장의 시트로** 받는다.
- 방향을 하나씩 따로 요청하는 것을 **금지한다.**

### 2.2 왜 (이 규칙을 되돌리지 마라)

방향을 따로 요청하면 **에셋 정합성이 깨진다.** 생성은 요청마다 독립적이므로 다음이 방향별로 달라진다.

- 캐릭터의 체형, 옷 주름, 장비 위치
- 색상 팔레트의 미세한 편차 (같은 "rust-red"가 요청마다 다른 값)
- 조명 방향과 그림자 길이
- 실루엣의 두께와 픽셀 밀도

한 장 한 장 보면 다 그럴듯한데, 게임에서 캐릭터를 회전시키면 **다른 사람이 빙글빙글 도는 것처럼 보인다.** 이건 후보정으로 고칠 수 없고 전부 다시 만들어야 한다.

한 번에 받으면 모델이 같은 컨텍스트 안에서 방향 간 일관성을 유지한다. 품질이 개별 생성보다 조금 떨어지더라도 **일관성이 우선이다.**

### 2.3 요청 시 고정할 것

한 요청 안에서 다음을 명시적으로 고정한다.

- 동일 인물/개체임을 명시 (체형, 복장, 장비, 색상 팔레트를 문장으로 못박는다)
- 카메라 각도와 스케일 (아이소메트릭 3/4 시점, 동일 거리)
- 광원 방향
- 배경은 투명 또는 단색 (셀 간 배경이 달라지면 안 된다)
- 셀 간격을 넉넉히 (잘림 방지)
- 이미지 안에 글자, 로고, 워터마크 금지

## 3. 후처리 (생성 직후 필수)

생성된 이미지는 **원본 그대로 게임에 넣지 않는다.** 다음을 거친다.

1. **픽셀 스냅(pixel snap)** — 생성 이미지는 안티에일리어싱과 서브픽셀 경계가 섞여 있다. 목표 해상도 격자에 맞춰 스냅한다.
   - 프로젝트는 `snap_2d_transforms_to_pixel` / `snap_2d_vertices_to_pixel`이 켜져 있고 텍스처 필터가 Nearest다. 스냅되지 않은 에셋을 넣으면 흐릿하게 뭉개진다.
2. **색 보정** — 스냅 후 팔레트를 정리한다. 생성 결과는 색 수가 과다하고 방향별로 미세하게 어긋난다.
   - 프로젝트 팔레트로 양자화하고, 8방향 전체에 **동일한 팔레트**를 적용한다.
   - 설계서 11.1: 저채도 자연색 + 현대 장비의 제한적 인공색 대비.

원본(생성 결과)과 런타임 PNG는 분리 보관한다 (성능 문서 2.1: "Aseprite 픽셀아트 — 런타임 PNG와 원본 분리").

## 4. 완료 판정

에셋 한 세트는 다음을 모두 만족해야 반영한다.

- [ ] 8방향(+ 필요 시 프레임)이 **한 번의 생성 요청**에서 나왔다.
- [ ] 8방향을 나란히 놓았을 때 같은 개체로 보인다. 체형·복장·장비·색이 흔들리지 않는다.
- [ ] 픽셀 스냅 완료. 목표 해상도에서 흐릿하지 않다.
- [ ] 8방향에 동일 팔레트가 적용됐다.
- [ ] 이미지 안에 글자·로고·워터마크가 없다.
- [ ] 타사 지식재산이 없다 (설계서 1.4).
- [ ] 실제 게임에서 회전시켜 확인했다. 정지 이미지 검수만으로 통과시키지 않는다.

## 5. 언제 만드는가

3주 차부터 최소 에셋만 제작한다 (사용자 지시). 핵심 시스템이 바뀌면 에셋을 다시 만들어야 하므로 그 전에는 회색 상자로 간다.

만들 것: 바닥 타일 8종 / 플레이어 대기·걷기 / 랩터 대기·걷기·추격 / 모닥불 / 돌·나무·붕대 아이콘 / 피와 발자국 / 최소 HUD

아직 만들지 않을 것: 공룡 5종 전체, 거대한 완성 맵, 캐릭터 커스터마이징, 모든 무기 애니메이션, Steam 캡슐 이미지, 완성 트레일러, 화려한 메인 메뉴, 수십 개 제작 아이템
