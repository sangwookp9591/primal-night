## 2. 사후 인터뷰 (플레이 직후, 유도 금지, 답변 그대로 받아적기)

1. 방금 왜 죽었다고(또는 위험했다고) 생각하나요? ← **"억울하다" vs "그때 ~했어야 했는데" 구분이 핵심 판정**
2. 랩터가 당신을 어떻게 찾았을까요?
3. 다음 판이 있다면 뭘 다르게 할 건가요?
4. 가장 긴장됐던 순간과 가장 지루했던 순간은?
5. (자유) 이해가 안 됐던 것 하나만 꼽는다면?

## 3. 성공 기준 집계 (5명 완료 후)

| 기준 (§8) | 목표 | 결과 | 통과 |
|---|---|---|---|
| 불 피우기 + 옷 장착을 설명 없이 수행 | 4/5 이상 | /5 | |
| 랩터 발견 원인을 말로 설명 | 4/5 이상 | /5 | |
| 서로 다른 위기 해결법 사용 (도망·불·미끼·은신·전투 중 상이한 조합) | 3/5 이상 | /5 | |
| 다음 판에 다른 선택을 시험하고 싶다고 발화 | 3/5 이상 | /5 | |
| 90초+ 무의미 걷기 반복 구간 | 0건 | 건 | |
| 사망 후 다음 행동을 즉시 이해 | 전원 | /사망자 | |

**최종 판단 (§9)**: 사망 후 반응이 "억울하다"인가, "그때 피 묻은 고기를 버렸어야 했는데"류인가?
→ 후자 다수면 통과. 전자 다수면 원인 전달(냄새·소리·피 흔적 피드백) 보강이 최우선 과제.

## 4. 결과 처리 규칙

- 통과 시에만 맵·공룡·레시피 확장 및 2단계 장기 생존 모드 착수 가능 (§6·§7 순서 원칙).
- 미통과 시: 실패한 기준별로 원인 가설 → 수정 태스크화 → 재테스트. 신규 콘텐츠 확장 금지 유지.
