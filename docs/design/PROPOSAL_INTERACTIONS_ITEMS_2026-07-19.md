# PRIMAL NIGHT — 추가 상호작용·아이템 기획안

> 작성: 2026-07-19, 코디네이터(Fable 5). 사용자 요청("추가적인 상호작용 및 아이템 기획안").
> 지위: **제안서.** 전 항목은 1차 사람 플레이테스트(§8) 통과 후 착수 후보다 — "검증 후에만 확장" 원칙(좀보이드 방향 §6·§9)을 따른다.
> 채택 기준: 각 항목이 정본 문장 — **"공룡과 싸우는 게임이 아니라, 내가 남긴 흔적 때문에 사냥당하는 게임"** — 을 강화하는가. 강화하지 못하면 탈락.

## 0. 설계 원칙 (전 항목 공통)

1. **모든 이득에는 흔적 대가**: 새 상호작용·아이템은 냄새·소리·시각 흔적 중 최소 하나를 남기거나, 흔적을 지우는 대신 시간·재료를 태운다.
2. **재료 다용도 충돌 유지**: 새 레시피는 기존 재료(hide/fiber/bone/sinew/wood/stone/숯)를 기존 용도와 경쟁시킨다. 신규 재료는 최소화.
3. **호스트 권위·저장 왕복·하네스 불변**: 구현 시 기존 계약(main.tscn 직접 로드 판정, JSON int 함정, 넷 복제 규칙)을 깨지 않는다.
4. **한 번에 하나**: 티어 순서로 1건씩 구현→GUT→실기→재미 판정 후 다음.

## 1. 상호작용 제안 (우선순위 순)

### T1 — 플레이테스트 직후 착수 후보

| # | 상호작용 | 무엇 | 강화하는 루프 | 흔적 대가 / 트레이드오프 | 난도 |
|---|---|---|---|---|---|
| I-1 | **흔적 지우기** | 피 웅덩이·BloodTrail 위에서 E 홀드(3초) → 흙으로 덮어 냄새 강도 대폭 감소 | 실수→수습. "그때 피를 덮었어야 했는데"를 실제 동사로 만든다 | 지우는 동안 무방비 + 손이 더러워져 잠시 자기 냄새 증가 | 하 — SmellSource 강도 조작 + 홀드 상호작용(기존 패턴) |
| I-2 | **돌 던지기** | 인벤의 stone을 조준 투척 → 낙하 지점에 1회성 소음 발생(랩터 유인) | 비대칭 해결법(§8 관찰 4번). 싸움 대신 주의 돌리기 | stone 소모(창 재료와 경쟁), 던진 방향 노출은 없음 — 대신 손에 든 걸 버리는 기회비용 | 하 — 활 투사체 코드 재사용 + NoiseEmitter |
| I-3 | **사체 끌기** | 랩터/사냥감 사체를 잡고 저속 이동 → 냄새 원천을 원하는 곳으로 이동 | 욕심→연쇄. 해체 장소 선택이 전략이 된다(거점에서 해체 vs 현장 해체) | 끄는 내내 피 냄새 트레일 생성 + 이동 속도 40% | 중 — 사체 노드 이동 + BloodTrail 연속 방출 |
| I-4 | **물 마시기/물 뜨기** | 강가(Z02 물가 타일)에서 E → 수분 회복. 물통(A-1) 있으면 담아가기 | 준비→귀환. 수분 축이 실제 동선을 만든다(물가는 사냥터이기도) | 물가는 개활지 — 접근 자체가 노출. 마시는 동안 시야 고정 | 하 — 물 타일 인접 판정 + 소비 |

## 3. 명시적 비추천 (검토 후 탈락)

- **총기·금속 도구**: 시대·정체성 불일치. 흔적 게임성을 화력으로 우회하게 만든다.
- **자동 포탑식 방어물**: 거점을 요새로 만들면 "귀환의 안도"가 "농성"으로 변질.
- **미니맵/레이더**: 감지 루프(냄새·바람·소리 읽기)를 UI로 대체 — 학습 재미 파괴.
- **인벤토리 대형 확장**: 욕심의 긴장은 용량 부족에서 나온다. small_pack 정도로 상한 유지.

## 4. 권장 착수 순서

1. 플레이테스트 결과에서 "원인 이해 실패" 신호가 나오면 → I-1(흔적 지우기)·I-8(귀 기울이기)부터: 규칙 가독성 보강.
2. "해결법 다양성 부족" 신호면 → I-2(돌 던지기)·A-4(뼈 피리): 비전투 해결 확장.
3. "동선 단조" 신호면 → I-4(물)·A-1(물통)·A-2(약초): 원정 동기 추가.
4. 신호 없이 전부 통과면 → T1 전체를 위 순서로.
