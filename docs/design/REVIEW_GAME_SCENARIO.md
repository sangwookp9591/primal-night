- **근거**: `scenes/main.tscn:21-93`는 Main 직속 평면 트리(World, Player, SurvivalDemo, SmellGrid, Raptor, NetSession, Players, NetMovement…NetResync, SessionClock, LoopObjective)다. §20.1은 이를 `Session/`, `Network/`, `WorldRoot/` 하위 트리로 재편해 제시한다.
- **문제**: 개별 노드는 현재/제안 태그가 있으나, **구조 재편 자체**가 변경 제안으로 라벨되지 않았다. 재편은 문서가 §20.1:1184에서 "유지하라"고 강조한 NetMovement→NetResync 신호 구독 순서를 건드리는 작업이다.
- **수정 제안**: §20.1 상단에 "이 트리는 목표 재구조화(변경 제안)이며 현재 main.tscn은 평면 구조"라는 한 줄을 추가하고, 재편을 자동 통합 테스트로 보호한다는 기존 문장과 연결.

### [MINOR] FIN-3 — §14.2 아이템 표의 `현재` 라벨이 미구현 컬럼과 같은 행에 병기됨
- **근거**: §14.2에서 stone/wood/raw_meat/bandage/bait 행에 **현재** 태그가 붙지만, 같은 행의 `내구/슬롯·희귀도`, `use_effect` 상세는 미구현 필드다(`item_data.gd`에 durability/rarity/category 없음).
- **문제**: 표기 규칙(§0)과 §14.1이 "추가 필드는 변경 제안"이라 보완하지만, 표만 스캔하면 행 전체를 구현 완료로 과대 해석할 여지.
- **수정 제안**: **현재** 태그를 아이템명이 아니라 "데이터 리소스 존재" 의미로 한정하는 각주를 §14.2 표 하단에 명시(이미 line 721에 유사 문장이 있으나 컬럼 단위 주의가 없음).

## 6. 미검증 항목 (코드/저장소로 확인 불가 — 추측 배제)

- **"Godot 4.7 stable" 릴리스 존재 여부**: 저장소는 `project.godot` features=4.7 + gl_compatibility를 선언하므로 문서와 **내부적으로 일관**하나, 4.7 stable이 실제 공개 릴리스인지는 저장소 밖 사실이라 확인 불가.
- **개별 벤치마크 코드 B04/B06/B10/B12**: §24·§25가 참조하나 `performance-budget` 문서 발췌에서 B02/B05/B08/B09만 직접 확인. 나머지 B코드의 정의 존재는 전량 대조하지 않음(저위험).
- **플레이테스트·밸런스 목표치**(예: 5팀 중 4팀 첫 15분 물·불 확보, 평균 60분 내 능선 도달, 완주율 등): 미측정 목표값이므로 검증 대상 아님.
- **정식 버전/2~4인/저장 규모 확장의 성능 실측**: 미구현이므로 목표로만 존재.
