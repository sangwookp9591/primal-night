PRIMAL NIGHT — UI 디자인 시스템 v0.1

저채도 자연색,
제한된 인공의 빛

설계서 11.1의 시각 방향을 UI 언어로 옮긴 보드. 세계는 저채도 자연색으로 가라앉고, 생존자의 현대 장비(손전등·계기·경보)만 제한적인 인공색을 낸다. HUD의 모든 강조색은 "장비가 내는 빛"이라는 규칙을 따른다.
